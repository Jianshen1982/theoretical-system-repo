──────────────────────────── A.0 总则 ────────────────────────────
判据先于测量,阈值先于数据,一经注册不因结果修改。协议的每次修订开
新版本并保留旧版全文于外部仓库;任何回溯性放宽不得"救活"已被判废的
候选(不可逆注册条款)。本协议对所有测量段运行(R# 编号)具有排他
管辖权:预注册之外的判据不产生定案。
────────────────────── A.1 管线五段与职责互斥 ────────────────────
预注册(P,判据成文)→ 生成(v#,构造脚本)→ 测量(R#,既定测量)
→ 识别(C,通道归档)→ 定案(D,双证汇合)。
执行测量的人不得临时修改判据;识别结果不得反向挑选测量;测量段全量
输出、不允许选择性引用。
────────────────────── A.2 识别通道次序 ──────────────────────────
通道次序不可跳越:
 1) 有理通道:容差 ε1 内匹配 p/q(q ≤ Qmax,p、q 互素);
 2) 二次根式通道:匹配 √m/k 或 a + b√m/k(有理参数界内搜索);
 3) 符号验证通道(R19 式核验):闭式坐标代入 → 有理化 → 通分归一
    → 字面恒等式。
前两通道须满足裕度判据:候选差 ≥ 10³ × 通道机器精度。符号验证不豁免
数值裕度——闭式候选必须先在数值层以足额裕度被"看见",方许进入符号
层定案;数值识别若通不过符号核验,判为识别失败(非数据错误),退回
测量段复核。
────────────────── A.3 判废标准:分母结构族检验 ──────────────────
识别出的 p/q,其分母 q 的素因子结构必须与构型的已知代数背景相容:
q 的素因子应出现在约束系统的消元结果(已知系数与判别式)或坐标域的
分母结构中。
现行版结构族(float64 输入):
    FAMILY = {3,9,27,81,729,531441(3 的幂)} × {17,19}
   (对应坐标域 K = Q(√2,√3,√6) 的分母素因子 {3 的幂} × {17,19}。)
判废实例的注册记录:
 - 373/1998(1998 = 2·3³·37,因子 37 无消元来源支撑,判为碰巧匹配
   —— |w|/Rc 保持开放 O-1);
 - 1069/4973(float32 输入期判废)。
判废仅清叙述层,定案数字零依赖(定案免疫声明)。
─────────────── A.4 溯源条款与外部意见纪律 ───────────────────────
每一定案数字携带完整证据链,格式:定案项 / 定案值 / 证据链 / 独立
佐证 / R# 编号 / v# 版本 / 复算记录。
外部来源的数值断言入正文前须逐条过 R19 式核验(闭式重建、残差清零、
独立复算)——本条款由两起历史实例(判别式误录 251682、双根误读为
对映两支)的动机性设立维持效力。
────────────────── A.5 弛豫收敛判据(生成段) ─────────────────────
生成段弛豫的终止条件与质量核验:
 1) 收敛判据:锁定子图距离平方目标 TGT = {8/3, 256/81, 200/57}
   (模型单位;Rc = 1 系为 {1, 32/27, 25/19})的残差 RMS < 10⁻¹⁵
    或迭代步数上限(300 LM 步);
 2) 内点判据:51 棱全内点(计数恰为 {45,4,2})、最大相对残差 < 10⁻³
   (放行线)且实测达 ~10⁻¹⁵(LM 精确解);
 3) 五重邻接普查:与塌缩点距离 = ℓ1 的顶点集合须为预期值之一
   ([1,11,12] 或镜像 [1,2,12],0 基索引);
 4) 结构残差:零档 max|dp|、对内切向重合、五重 dp 全等、球面归一
    四项综合残差 < 10⁻¹²(实测 2.00×10⁻¹⁵ / 8.88×10⁻¹⁶,双支);
 5) 坐标残差:最终网格全部低于 10⁻¹⁵(相对尺度)。
──────────────── A.6 定向约定(v2 注册;报告 8 起强制) ────────────
测量段一切法向量取号须满足:nx > 0(对映两支的统一朝向;nz 接近零,
绝对定向以 nx 主导)。float32 输入期的 ny 判据(|ny − 1/3| < 阈值)
已废除——历史报告 8 中 ny − 1/3 = −0.667 的异常系 0 基索引误锚
(G.1-2 连带),由 A.5 结构残差判据取代其对测量质量的管辖权;n 的
身份验证改由四对差向量共线性承担。附注册说明:该判废同时解释了
报告 8 的 "ny − 1/3 = −6.667e−01" 异常读出——判据与数据无恙,锚点
标签损坏。
────────────── A.7 阈值绑定(A.8 / A.8′ / A.8 补则 / A.8″) ────────
A.8(容差与数据精度绑定):ε1 不是固定常数,而是测量精度的函数——
识别只允许在"数据可信位数"内进行,超出即拒绝。现行版绑定表:
    输入精度                相对阈值 REL_TOL    有理分母上限 Qmax
    float64(LM 精化)       10⁻¹²               10⁶
    float32(Blender 回退)  10⁻⁷                5000
A.8′(结构残差报告义务):凡匹配成功,必须同时报告结构残差(识别值
与测量值之差)与该残差相对绑定阈值的裕度;裕度不足的匹配降级为
"碰巧"。阈值下限:REL_TOL ≥ 10⁻¹²;结构残差驱动调整时
REL_TOL = max(10⁻¹², 10³ × 综合残差)(实测 A.5 综合残差
2.00×10⁻¹⁵ ⟹ REL_TOL = 2.0×10⁻¹²,报告 10v2 执行值)。
A.8 补则(float32 拒绝事件的注册依据):任何定案级证据量必须超过该
级噪声底两个数量级以上。注册执行记录:float32 筛查中塌缩全等残差
4.8×10⁻⁶ 与噪声底 ~10⁻⁶ 同量级(比值 < 10²)⟹ float32 全线退出
定案链,降级为收敛监控。塌缩的定案资格只在 float64 与符号层成立。
A.8″(生效与冲突条款):本协议与论文正文冲突时以正文定案章为准;
协议修订不追溯既往运行——历史运行的判废/定案结论按其注册时版本判据
维持(历次结论均经现行版复核无翻转,见 A.9)。
